# VANBOOK PH

Responsive Next.js application with Supabase Auth, PostgreSQL, and private
Storage, intended for Vercel hosting.

Current feature: operator business applications and administrator review,
including drafts, private documents, corrections, review history, and a
configurable document checklist. Vehicle verification and the requests/quotes
marketplace remain separate later features.

- [Run and verify the application](web/README.md)
- [Set up the existing hosted Supabase project using SQL Editor](supabase/README.md)

Docker is not required. The hosted schema and first administrator must be set up
with the reviewed SQL files before the operator/admin workspaces can be used.
